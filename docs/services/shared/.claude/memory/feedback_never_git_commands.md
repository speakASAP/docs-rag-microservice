# CRITICAL: Never Run Git Commands

**Rule:** NEVER execute `git add`, `git commit`, `git push`, or any destructive git commands. Not once. Not under any circumstances. Not even when "convenient."

**Why:** Git operations hard to undo. The user must always see the changes and control these actions.

**How to apply:**

- Never ask for permission to run git commands
- Never suggest "just let me commit this"
- Never run git commands proactively

**Exception:** None. Zero exceptions. This is non-negotiable.

**If tempted:** Remember the user has told you this multiple times across multiple sessions. They are serious about this.
