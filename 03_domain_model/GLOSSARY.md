## Terms
- Agent context: Token-budgeted context block returned by `/retrieval/agent-context` for direct use by AI agents.
- Chunk: A markdown-derived document segment stored with metadata and vector representation.
- Ecosystem repository: A service repository under the shared platform documentation scope.
- Embedding: Numeric representation generated by Ollama using the configured embedding model.
- Ingestion job: A tracked process that syncs repository documentation, chunks it, embeds it, and stores it for retrieval.
- Qdrant collection: The vector database collection `ecosystem-docs` used for documentation chunks.
- Repository source of truth: The original service repository documentation, which remains authoritative over indexed copies.
- Service-to-service JWT: HS256 bearer token required for all endpoints except `/health`.
- Snapshot: A copied documentation view under `docs/services/<repo-name>/` refreshed by `scripts/sync-docs-snapshot.sh`.

## Validation
